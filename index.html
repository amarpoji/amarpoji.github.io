CrewAI Hadith Research Agent

Latest

As a student of Islamic knowledge, I know finding an authentic hadith on a topic is exhausting — the corpus spans hundreds of books. And trusting an LLM blindly is dangerous: one hallucinated word in the matn corrupts the narration. So this agent searches only vetted sources (sunnah.com, shamela.ws) and returns every source URL for double-checking — authenticity guaranteed, search time slashed.
